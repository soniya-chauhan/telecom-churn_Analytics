 Telecom Customer Churn Analytics

An end-to-end Data Analytics project that analyzes customer churn using Python, Pandas, MySQL, SQL, and Power BI.

The project follows a complete analytics workflow — from raw dataset loading and data cleaning to SQL-based analysis, interactive dashboard development, and business insights.

# Project Overview

Customer churn is a major challenge for telecommunications companies because losing existing customers can directly impact revenue and business growth.

This project analyzes telecom customer data to identify:

- Overall customer churn
- High-risk customer segments
- Churn patterns across contracts and services
- Relationship between tenure and churn
- Payment and billing patterns
- Customer charge behavior

The final solution combines Python, MySQL analysis, SQL queries, and Power BI visualization to convert raw customer data into actionable business insights.

---

# Business Problem

The telecom company wants to understand:

- How many customers are leaving?
- What is the overall churn rate?
- Which customer segments have higher churn?
- Does contract type affect churn?
- How does customer tenure relate to churn?
- Which internet services and payment methods show higher churn?
- How can the company improve customer retention?

The goal is to use data to support targeted and data-driven customer retention strategies.

# Project Objectives

- Clean and validate the raw customer dataset.
- Build a structured ETL workflow using Python and Pandas.
- Store and analyze the cleaned data using MySQL.
- Perform business-focused SQL analysis.
- Calculate important customer churn KPIs.
- Build an interactive Power BI dashboard.
- Identify key churn patterns and customer segments.
- Provide actionable business recommendations.

# Dataset

The project uses the Telecom Customer Churn dataset, containing customer-level information related to demographics, services, contracts, billing and churn status.
The dataset contains approximately 7,043 customer records.

# Conclusion
This project demonstrates an end-to-end Telecom Customer Churn Analytics workflow, from raw data preparation to business intelligence. The dataset was cleaned and validated using Python and Pandas, analyzed using MySQL and SQL, and transformed into an interactive Power BI dashboard for business reporting.
The analysis identified 7,043 customers, including 1,869 churned customers, resulting in an overall 26.54% churn rate. The project examined churn patterns across contract type, tenure, internet service, payment method, customer demographics, and billing behavior.
Overall, the project shows how data can be transformed into actionable business insights that help identify high-risk customer segments and support targeted retention strategies. It also provides a foundation for future improvements such as machine-learning-based churn prediction, customer risk scoring, and automated retention recommendations.
